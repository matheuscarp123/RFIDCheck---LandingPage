# RFIDCheck — landing page (GitHub Pages)

## Como publicar
1. Crie um repositório no GitHub e envie TODO o conteúdo desta pasta (mantendo as pastas `assets/`, `hungary/`, `slovakia/`...).
2. Settings → Pages → Source: *Deploy from a branch* → branch `main` / pasta `/ (root)` → Save.
3. Seus links ficam assim (com a barra no final):
   - https://USUARIO.github.io/REPO/            (inglês)
   - https://USUARIO.github.io/REPO/hungary/ · slovakia/ · czechia/ · poland/ · croatia/ · serbia/ · romania/ · bulgaria/
   Com domínio próprio, o prefixo `/REPO` some: seusite.com/hungary/

## Vídeos
Edite `videos-config.js` e cole o link do YouTube (ou só o ID) de cada país. País vazio usa o vídeo de `en`.

## Checkout
Troque `CHECKOUT_URL` no fim do `videos-config.js` pelo seu link de pagamento (€99).

## Fornecedores por país
Edite `hardware-config.js`.
